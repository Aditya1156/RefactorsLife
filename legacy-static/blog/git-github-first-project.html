Git & GitHub for Beginners: Set Up and Upload Your First Project

Install Git, connect it to GitHub, and push your first repository — the exact commands, and what each one does.

Git is a tool on your computer that tracks every change you make to your code. GitHub is a website that stores those Git projects online, so you can back them up, share them and collaborate. You need both. Prefer Hindi? Watch Git & GitHub explained in Hindi.

1. Install Git

  • Windows: download the installer from git-scm.com. The default options are fine.
  • macOS: run xcode-select --install in Terminal, or brew install git.
  • Linux (Ubuntu/Debian): sudo apt install git.

Check it worked:

git --version

2. Tell Git who you are

Every commit is signed with a name and email. Use the same email as your GitHub account:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main

3. Create a repository on GitHub

  1. Sign in to github.com and click New repository.
  2. Give it a name, e.g. my-first-project.
  3. Leave “Add a README” unchecked — we'll push our own files.
  4. Click Create repository and copy the URL it shows.

4. Push your project

Open a terminal in your project folder (in VS Code: Terminal → New Terminal) and run:

git init                      # start tracking this folder
git add .                     # stage every file
git commit -m "first commit"  # save a snapshot
git remote add origin https://github.com/<you>/my-first-project.git
git push -u origin main       # upload to GitHub

Refresh the GitHub page — your files are there.

5. Signing in from the terminal

GitHub doesn't accept your account password for git push. The easiest options:

  • Windows: Git's installer includes a credential manager — a browser window opens to sign in the first time you push.
  • Any OS: install the GitHub CLI and run gh auth login.
  • Or create a personal access token in Settings → Developer settings and paste it when asked for a password.

6. Your everyday loop

After the first push, every change is just three commands:

git add .
git commit -m "describe what you changed"
git push
Commit small and often, with messages that say why. Future you — and recruiters reading your GitHub — will thank you.
