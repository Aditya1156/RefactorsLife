New Laptop Dev Setup Checklist

Everything a CS / IT student needs on a fresh laptop, in the order to install it. Install only the languages your courses actually use.

R/refactorslife.in

1 · Editor

  • Install VS Code from code.visualstudio.com
  • Turn on Auto Save and Format on Save in settings
  • Sign in to sync settings across devices
  • Learn 3 shortcuts: Command Palette, Quick Open, multi-cursor

2 · Must-have extensions

  • Language packs: C/C++, Python, Extension Pack for Java
  • Prettier for consistent formatting
  • GitLens to see who changed what, and when
  • Error Lens to show errors inline
  • Live Server for HTML/CSS/JS projects

3 · Git & GitHub

  • Install Git from git-scm.com (macOS: xcode-select --install)
  • Set your name and email with git config --global
  • Create a GitHub account with a professional username
  • Sign in from the terminal: GitHub CLI (gh auth login) or an SSH key
  • Push one test repo to confirm everything works

4 · Languages & runtimes

  • C/C++ compiler: MinGW-w64 via MSYS2 (Windows), Xcode tools (macOS), build-essential (Linux)
  • Python 3 from python.org. On Windows, tick "Add to PATH"
  • Node.js LTS for web development
  • Java JDK (LTS) if your course or DSA practice uses Java
  • Verify each one with --version in a new terminal

5 · Free student perks

  • Apply for the GitHub Student Developer Pack
  • Activate GitHub Copilot (free for verified students)
  • Claim a JetBrains student licence if you use IntelliJ / PyCharm
  • Claim a free domain from the pack for your portfolio

6 · Habits that save you later

  • One ~/projects folder; never code on the Desktop
  • Every project in Git, pushed to GitHub
  • A short README in every repo
  • Back up notes and files to the cloud
  • Use a password manager and turn on 2FA everywhere
