Git & GitHub Cheat Sheet

Every command a beginner needs, in the order you'll need it. Pin it next to your screen.

R/refactorslife.in

1 · One-time setup // once per laptop

git --versionCheck Git is installed
git config --global user.name "Your Name"Name on your commits
git config --global user.email "you@mail.com"Use your GitHub email
git config --global init.defaultBranch mainNew repos start on main

2 · Start a project

git initStart tracking the current folder
git clone <url>Download a repo from GitHub
git remote add origin <url>Link your folder to a GitHub repo
git push -u origin mainFirst upload; sets the default

3 · The daily loop // 90% of your Git life

git statusWhat changed? Run it often
git add .Stage every change
git add <file>Stage one file
git commit -m "message"Save a snapshot
git pushUpload commits to GitHub
git pullDownload teammates' changes

4 · Branches

git branchList branches
git switch -c feature-xCreate and move to a branch
git switch mainGo back to main
git merge feature-xBring a branch into the current one
git branch -d feature-xDelete a merged branch

5 · See history

git log --oneline --graphCompact history
git diffUnstaged changes
git diff --stagedWhat you're about to commit
git show <commit>Details of one commit

6 · Undo mistakes // don't panic

git restore <file>Discard unsaved changes to a file
git restore --staged <file>Unstage, keep the changes
git commit --amendFix the last commit (before pushing)
git revert <commit>Safely undo a pushed commit
git stash / git stash popPark changes, bring them back
Tip: add a .gitignore so node_modules, .env and build files never get committed. Watch the walkthrough: youtube.com/@RefactorsLife
